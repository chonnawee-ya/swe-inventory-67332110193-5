# AI-Assisted Text Wireframe (ASCII Layout) - Lab 04

เอกสารนี้รวบรวมแบบร่างโครงสร้างหน้าจอแบบตัวอักษร (ASCII Text Wireframe) จำนวน 3 หน้าจอ ออกแบบตาม Persona ของพนักงานคลังสินค้า (ทักษะเทคโนโลยีระดับ 2/5) และเป็นไปตามหลักการ Usability & Accessibility (WCAG 2.1 AA)

---

## 1. หน้า Login (เข้าสู่ระบบ)

### Prompt ที่ใช้สร้าง:
```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้า Login" ของระบบ inventory
กลุ่มผู้ใช้: พนักงานคลังสินค้า ทักษะเทคโนโลยีระดับ 2/5 ใช้งานคอมพิวเตอร์เป็นหลัก

ข้อกำหนด usability:
- มีช่องกรอก: ชื่อผู้ใช้ (Username)*, รหัสผ่าน (Password)*
- มีปุ่มแสดง/ซ่อนรหัสผ่าน (Toggle Password Visibility)
- ปุ่ม "เข้าสู่ระบบ" (Primary) โดดเด่น ชัดเจน
- แสดงสถานะข้อผิดพลาดเมื่อกรอกรหัสผ่านผิด พร้อมคำแนะนำวิธีแก้

ข้อกำหนด accessibility:
- มี Visible Label เหนือช่องกรอกเสมอ
- ช่องบังคับมีเครื่องหมาย *
- Error message มีไอคอน [!] และข้อความอธิบายชัดเจน ไม่ใช้แค่สีแดง
- ลำดับการกด Tab เป็นธรรมชาติ (บนลงล่าง)
```

### ASCII Wireframe Layout:

### คำอธิบาย Usability & Accessibility:
* **Visible Labels:** วางป้ายกำกับด้านบนช่องกรอกตลอดเวลา ทำให้ผู้ใช้ไม่ลืมแม้กำลังพิมพ์อยู่
* **Password Toggle:** มีปุ่มรูปดวงตาสำหรับเปิดดูรหัสผ่าน ช่วยลดปัญหาพิมพ์รหัสผ่านผิดเนื่องจากผู้ใช้สูงวัยหรือสายตาไม่เอื้ออำนวย
* **Informative Error Message:** เมื่อล็อกอินผิดพลาด มีไอคอน `[!]` และระบุคำแนะนำ (เช่น ให้ตรวจ Caps Lock)

## 2. หน้า Dashboard (แผงควบคุมและสต็อกสินค้า)

### Prompt ที่ใช้สร้าง:
```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้า Dashboard" ของระบบ inventory
กลุ่มผู้ใช้: พนักงานคลังสินค้า ทักษะ 2/5 ดูแลทั้งสินค้าที่จับต้องได้และสินค้าดิจิทัล

ข้อกำหนด usability:
- แสดงการสรุปยอด: จำนวนสินค้าทั้งหมด, รายการสินค้าสต็อกต่ำ, สินค้าดิจิทัล
- มีปุ่มทางลัด "+ บันทึกสินค้าใหม่" เด่นชัดมุมบนขวา
- ตารางแสดงรายการสินค้า: แยกคอลัมน์ชนิดสินค้า (จับต้องได้ / ดิจิทัล) ชัดเจน
- มีแถบเตือนสินค้าใกล้หมด (Low Stock Warning)

ข้อกำหนด accessibility:
- ชุดสีมี contrast ผ่านเกณฑ์
- สถานะเตือนไม่ได้ใช้แค่สี แต่มีข้อความกำกับ เช่น "[เตือน: ใกล้หมด 2 ชิ้น]"
```

### คำอธิบาย Usability & Accessibility:
* **Product Type Badge:** แยกประเภท `[จับต้องได้]` กับ `[ดิจิทัล]` ชัดเจนในตารางสินค้า สินค้าดิจิทัลแสดงจำนวนเป็น "ไม่จำกัด" ป้องกันความสับสน
* **Multi-modal Low Stock Warning:** รายการที่ใกล้หมดมีทั้งป้ายข้อความ `(ใกล้หมด)` และสัญลักษณ์ `[!]` ประกอบกับสีแจ้งเตือน เพื่อให้ผู้มีความบกพร่องทางการมองเห็นสี (Color Blindness) รับรู้ได้ทันที
* **Prominent Add Button:** วางปุ่มบันทึกสินค้าใหม่ไว้มุมบนขวาในตำแหน่งสะดุดตา ช่วยให้ทำภารกิจหลักได้ทันที

## 3. หน้า Add Product (บันทึกสินค้าใหม่)

### Prompt ที่ใช้สร้าง:
```text
ช่วยออกแบบ text wireframe (ASCII layout) สำหรับ "หน้า Add Product" ของระบบ inventory
กลุ่มผู้ใช้: พนักงานคลังสินค้า ทักษะ 2/5 กลัวการพิมพ์ผิดช่อง

ข้อกำหนด usability:
- ฟอร์มมีฟิลด์: ชื่อสินค้า*, รหัสสินค้า*, ชนิดสินค้า* (จับต้องได้/ดิจิทัล), หมวดหมู่, จำนวน*, ราคา*, ลิงก์ดาวน์โหลด (เฉพาะดิจิทัล)
- ปุ่ม "บันทึกข้อมูล" (Primary) และ "ยกเลิก" (Secondary) อยู่มุมล่างขวา
- แสดง Inline Validation Error ใต้ฟิลด์ และ Success Banner ด้านบนเมื่อบันทึกสำเร็จ

ข้อกำหนด accessibility:
- ทุกฟิลด์มี Visible Label และ Required mark (*)
- Error message ชี้แจงวิธีแก้ไขชัดเจน
- ลำดับ Tab เป็นระเบียบ (บนลงล่าง)
```

### คำอธิบาย Usability & Accessibility:
* **Dynamic Form by Product Type:** เมื่อเลือก "สินค้าดิจิทัล" ฟิลด์จำนวนสินค้าจะถูกปิดการใช้งานอัตโนมัติ (เป็น "ไม่จำกัด") และแสดงฟิลด์ URL ลิงก์ดาวน์โหลดแทน
* **Actionable Inline Error:** ไม่ขึ้นแค่ข้อความสีแดง แต่มีคำอธิบายชัดเจนว่า "โปรดระบุจำนวนเต็มตั้งแต่ 0 ขึ้นไป"
* **Clear Button Hierarchy:** ปุ่มยกเลิกและบันทึกมีน้ำหนักสายตาต่างกันชัดเจน โดยปุ่มบันทึกเป็น Primary Action เด่นชัด ป้องกันการกดผิด
