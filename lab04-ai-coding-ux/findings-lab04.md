# Interview Findings - Lab 04

## Interviewee (role-play หรือคนจริง)
* **บทบาท:** พนักงานคลังสินค้าและดูแลสต็อกสินค้า (ร้านจำหน่ายอุปกรณ์และสื่อการเรียนรู้ดิจิทัล)
* **ประสบการณ์:** ทำงานดูแลสต็อกและบันทึกข้อมูลสินค้ามา 3 ปี (ใช้ Spreadsheet/Excel เป็นหลัก)
* **อุปกรณ์หลัก:** คอมพิวเตอร์ตั้งโต๊ะ (PC Windows จอ 1080p) ประจำโต๊ะคลังสินค้า และสมาร์ตโฟน Android ประจำตัว

## Questions & Answers Summary
1. **ทุกวันนี้ทำงานกับสินค้าในคลังอย่างไรตั้งแต่เช้าถึงเย็น:**
   * ช่วงเช้าตรวจรับสินค้าเข้าคลัง บันทึกรายการลงใน Excel ที่แชร์กับแผนกขาย มีทั้งสินค้าแบบจับต้องได้ (เช่น บอร์ดไมโครคอนโทรลเลอร์, หนังสือเล่ม) และสินค้าดิจิทัล (เช่น ซีเรียลโค้ดคอร์สเรียน, อีบุ๊ก PDF ที่ต้องส่งลิงก์ดาวน์โหลด)
   * ช่วงบ่ายตัดสต็อกตามใบสั่งซื้อของลูกค้า
   * ช่วงเย็นสรุปยอดคงเหลือและตรวจสอบสินค้าใกล้หมดเพื่อส่งต่อให้ฝ่ายจัดซื้อ

2. **ขั้นตอนไหนเสียเวลาหรือต้องระวังมากที่สุด:**
   * ตอนกรอกข้อมูลสินค้าใหม่ในหน้า Spreadsheet เพราะช่องข้อมูลเยอะมาก กลัวกรอกผิดช่อง โดยเฉพาะการแยกประเภทระหว่างสินค้าที่มีสต็อกนับชิ้นได้ กับสินค้าดิจิทัลที่ไม่มีวันหมด
   * ตอนบันทึกเสร็จ ไม่แน่ใจว่าข้อมูลบันทึกสำเร็จหรือยัง เพราะบางครั้งไฟล์ค้างหรือสูตรเพี้ยน

3. **เคยเกิดปัญหาอะไรกับการบันทึกข้อมูลที่ยังจำได้:**
   * เคยมีกรณีสั่งซื้อสินค้าดิจิทัล แต่เพื่อนร่วมงานไปกรอกจำนวนคงเหลือเป็น 0 ทำให้ระบบเข้าใจว่าของหมด ทั้งที่เป็นไฟล์ดาวน์โหลด
   * เคยพิมพ์ราคาตกหล่น หรือพิมพ์ตัวอักษรลงช่องตัวเลข ทำให้สูตรคำนวณมูลค่ารวมทั้งตารางแสดง `#VALUE!` ต้องไล่หาแก้กันครึ่งวัน

4. **ถ้าระบบใหม่ทำเรื่องหนึ่งได้ดีขึ้นมาก อยากให้เป็นเรื่องอะไร:**
   * ต้องการหน้าบันทึกสินค้า (Add Product) ที่มีฟอร์มชัดเจน มีป้ายบอกชื่อช่อง (Label) ค้างไว้ตลอดเวลา ไม่สับสน มีตัวเลือกประเภทสินค้า (จับต้องได้ vs ดิจิทัล) และหน้า Dashboard ที่แจ้งเตือนของใกล้หมดทันที

## Needs
* ต้องการฟอร์มบันทึกสินค้าที่แยกฟิลด์ชัดเจน มีช่องเลือกประเภทสินค้า (สินค้าที่จับต้องได้ / สินค้าดิจิทัล) อย่างชัดเจน
* ต้องการระบบตรวจสอบความถูกต้องของข้อมูลทันที (Inline Validation) และมีข้อความแจ้งเตือนที่เข้าใจง่ายเมื่อกรอกผิด
* ต้องการเห็นข้อความยืนยันการบันทึกสำเร็จที่ชัดเจน และมีหน้า Dashboard แสดงรายการสินค้าใกล้หมดแบบเรียลไทม์

## Pain Points
* ใน Spreadsheet ไม่มี Label กำกับชัดเจน พอกรอกแล้ว placeholder หาย ลืมว่าช่องไหนคืออะไร
* สับสนระหว่างสินค้าจับต้องได้กับสินค้าดิจิทัล เพราะสินค้าดิจิทัลไม่มีสต็อกหมด แต่ตารางเดิมบังคับให้กรอกจำนวน
* ไม่มีระบบแจ้งเตือนสต็อกต่ำ (Low Stock Alert) ล่วงหน้า ทำให้สินค้าขาดสต็อกโดยไม่รู้ตัว
* ปุ่มบันทึกหรือการทำงานไม่มี Feedback ยืนยัน ทำให้ไม่มั่นใจว่าข้อมูลถูกบันทึกจริงหรือไม่

## Surprises
* ผู้ใช้ระบุว่าแม้จะทำงานมา 3 ปี แต่ยังมีความกังวลเรื่องการพิมพ์ผิดช่องอยู่ตลอดเวลา โดยเฉพาะเมื่อต้องรีบกรอกข้อมูลตอนมีออร์เดอร์เข้าพร้อมกันจำนวนมาก
* ผู้ใช้ไม่ต้องการฟีเจอร์ซับซ้อน แต่ให้ความสำคัญสูงสุดกับ "ขนาดปุ่มที่กดง่าย", "ตัวหนังสือที่อ่านชัดเจนไม่กลืนกับพื้นหลัง" และ "ข้อความบอกวิธีแก้ปัญหาเวลาใส่ข้อมูลผิด"

## Point of View (1 ประโยค)
พนักงานคลังสินค้าที่มีทักษะเทคโนโลยีระดับปานกลาง ต้องการหน้าจอบันทึกสินค้า (Add Product) ที่มีป้ายกำกับช่องกรอกคงค้าง มีตัวเลือกประเภทสินค้าจับต้องได้/ดิจิทัลที่ชัดเจน และมีข้อความแนะนำวิธีแก้ไขเมื่อกรอกผิด เพราะการกรอกข้อมูลผิดพลาดในแบบฟอร์มเดิมทำให้เสียเวลาตรวจสอบแก้ไขและทำให้ระบบสต็อกเสียหาย
