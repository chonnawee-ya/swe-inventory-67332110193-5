# Persona: สมศักดิ์ จัดการดี (Somsak)

## ข้อมูลทั่วไป
* **อายุ:** 32 ปี
* **ตำแหน่ง:** พนักงานบันทึกและจัดการสต็อกสินค้าประจำคลังสินค้า
* **ประสบการณ์:** 3 ปี ในการจัดการสินค้าทั้งแบบจับต้องได้ (Physical Hardware) และสินค้าดิจิทัล (Digital Software/Licenses)
* **อุปกรณ์หลัก:** คอมพิวเตอร์ตั้งโต๊ะ (PC Windows) ในคลังสินค้า + จอภาพ 21.5 นิ้ว Full HD
* **ทักษะเทคโนโลยี:** 2 / 5 (ใช้งานโปรแกรมพื้นฐาน เช่น พิมพ์งาน, ใช้เบราว์เซอร์, และ Spreadsheet ได้ แต่ไม่คุ้นชินกับการแก้ปัญหาทางเทคนิคเชิงลึก กลัวระบบล่มหากกดปุ่มผิด)

## Quote ที่บ่งบอกตัวตน
> "ผมกลัวที่สุดคือพิมพ์ตัวเลขผิดช่องหรือลืมเลือกประเภทสินค้า เพราะถ้าสต็อกเพี้ยน ต้องมานั่งรื้อเอกสารตรวจย้อนหลังครึ่งค่อนวัน"

## Goals
1. สามารถบันทึกสินค้าเข้าคลัง (ทั้งสินค้าที่จับต้องได้และสินค้าดิจิทัล) ได้อย่างถูกต้อง รวดเร็ว โดยไม่ต้องสลับหน้าจอไปมา
2. สามารถตรวจดูยอดคงเหลือและรับการแจ้งเตือนสินค้าใกล้หมด (Low Stock Alert) ได้ทันทีจากหน้าจอ Dashboard โดยไม่ต้องคำนวณเอง

## Frustrations
1. แบบฟอร์มเดิมไม่มี Label กำกับถาวร เมื่อเริ่มพิมพ์ข้อความ Placeholder จะหายไป ทำให้สับสนว่ากำลังกรอกข้อมูลช่องใด
2. สับสนระหว่างสินค้าจับต้องได้กับสินค้าดิจิทัล เนื่องจากระบบเดิมบังคับใส่จำนวนสต็อกสำหรับสินค้าดิจิทัล ทั้งที่สินค้าดิจิทัลไม่จำกัดสต็อกแต่ต้องการลิงก์ไฟล์
3. เมื่อเกิดข้อผิดพลาดในการกรอก (Validation Error) ระบบเดิมแจ้งเพียงคำว่า "เกิดข้อผิดพลาด" โดยไม่ระบุช่องและไม่บอกวิธีแก้ไขที่ชัดเจน

## สิ่งที่ต้องการจากระบบใหม่
1. หน้าจอแบบฟอร์มบันทึกสินค้า (Add Product) ที่แยกประเภทสินค้าชัดเจน มี Label ค้างไว้เหนือช่องกรอกเสมอ และมี Inline Error Message ชี้จุดผิดพร้อมวิธีแก้ไข
2. ปุ่มดำเนินการหลัก (Primary Action) มีขนาดใหญ่ ตำแหน่งชัดเจน และแสดงข้อความตอบรับสถานะ (Success Banner/Toast) ชัดเจนเมื่อบันทึกข้อมูลเรียบร้อย

## User Journey Map: บันทึกสินค้าเข้าคลังหนึ่งรายการ

| ขั้น | ผู้ใช้ทำอะไร | รู้สึกอย่างไร | จุดสะดุด (Pain Point) |
| :--- | :--- | :--- | :--- |
| **1. เปิดระบบ** | เปิดเว็บเบราว์เซอร์และล็อกอินเข้าสู่ระบบคลังสินค้า | กังวลเล็กน้อย กลัวจำรหัสผ่านไม่ได้ | ช่องกรอกไม่มีปุ่มเปิด-ปิดดูรหัสผ่าน และปุ่ม Login กลืนไปกับพื้นหลัง |
| **2. หาเมนูที่ใช้บันทึก** | มองหาปุ่มหรือเมนูสำหรับเพิ่มสินค้าใหม่จากหน้า Dashboard | กระตือรือร้น อยากทำงานให้เสร็จเร็ว | เมนูในหน้า Dashboard มีหลายปุ่มและใช้คำศัพท์ภาษาอังกฤษที่เข้าใจยาก |
| **3. กรอกข้อมูลสินค้า** | พิมพ์ชื่อสินค้า เลือกระหว่างสินค้าจับต้องได้/ดิจิทัล กรอกจำนวนและราคา | ลังเล เครียด กลัวกรอกผิดช่อง | ช่องกรอกไม่มี Visible Label พิมพ์แล้วลืมว่าช่องไหนคือรหัสหรือราคา และไม่มีตัวเลือกแยกประเภทสินค้าดิจิทัล |
| **4. กดบันทึก** | เลื่อนเมาส์ไปกดปุ่ม "บันทึกข้อมูล" | ลุ้น ไม่แน่ใจว่าจะผ่านหรือไม่ | ปุ่ม "บันทึก" กับปุ่ม "ยกเลิก" วางติดกันและสีคล้ายกัน กลัวเผลอกดผิด |
| **5. ตรวจว่าบันทึกสำเร็จ** | รอผลการบันทึกข้อมูลสินค้า | โล่งอกเมื่อเห็นสถานะชัดเจน | ระบบไม่มีข้อความยืนยันความสำเร็จ ทำให้ไม่แน่ใจว่าข้อมูลเข้าระบบหรือยัง จึงเผลอกดบันทึกซ้ำ |

### จุดสะดุดที่ต้องแก้ไขใน Mockup (Target Improvement)
* **จุดสะดุดที่เลือก:** ขั้นที่ 3 (กรอกข้อมูลสินค้า) — ผู้ใช้ไม่แน่ใจว่ากำลังกรอกช่องใดเมื่อ Placeholder หายไป และไม่สามารถระบุชนิดสินค้าดิจิทัลได้
* **แนวทางแก้ไขบนหน้าจอ:** บนหน้าจอ **Add Product** ต้องเพิ่มป้ายกำกับ (Visible Label) ชัดเจนค้างไว้เหนือทุกช่องกรอก พร้อมสัญลักษณ์ดอกจันสีแดง `*` สำหรับช่องบังคับ และมีตัวเลือก Radio Button/Dropdown แยกประเภท "สินค้าที่จับต้องได้" (Physical) กับ "สินค้าดิจิทัล" (Digital File) อย่างชัดเจน
